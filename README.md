# Multimodal VQA Annotation and Prompt Engineering

**Timeline:** April 2026  
**Category:** Main project

This project develops a structured annotation and prompt-engineering workflow for visual question answering (VQA). The work defines question-answer examples, cognition-oriented labels, bounding-box context, human-in-the-loop review, and error analysis for multimodal language-model behavior.

## Stack

COCO, VQA, multimodal NLP/LLMs, structured data annotation, prompt engineering, cognition taxonomy, bounding boxes, human-in-the-loop review, and error analysis.

## Repository contents

- `docs/` — task definition and project documentation.
- `reports/` — the project-specific report.
- `data/README.md` — dataset provenance and excluded-data instructions.

The repository emphasizes the documented experimental protocol and annotation design; raw image/question corpora are not redistributed.
