# Data statement

The project references the COCO image corpus and VQA question/answer data. These datasets originate from the official COCO and VQA releases and are excluded because they are large, separately licensed datasets. The local course files were stored under the UNT NLP project folder.

Obtain COCO and VQA from their official sources, keep images and annotations outside this repository, and point the annotation workflow to those local paths. The expected inputs are image identifiers, questions, answers, optional bounding boxes, and structured cognition/error labels.
